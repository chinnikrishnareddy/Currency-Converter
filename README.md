# Currency Converter

A responsive and interactive **Currency Converter Web Application** built using **HTML, CSS, and JavaScript** with real-time exchange rate API integration.
This project allows users to convert currencies instantly with live exchange rates through a clean and user-friendly interface.

## 🚀 Features

* 🌍 Real-time currency conversion
* 🔄 Live exchange rates using API integration
* 💻 Responsive and modern UI
* ⚡ Fast and lightweight application
* 🎨 Simple and user-friendly design
* 📱 Works on desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Exchange Rate API

## 📂 Project Structure

```bash
Currency-Converter/
│── index.html
│── style.css
│── script.js
│── code.js
│── README.md
```

## ⚙️ How It Works

1. Select the source currency.
2. Select the target currency.
3. Enter the amount.
4. Click the convert button.
5. Get the converted amount instantly using live exchange rates.

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/chinnikrishnareddy/Currency-Converter.git
```

Open the project folder:

```bash
cd Currency-Converter
```

Run the project by opening `index.html` in your browser.
